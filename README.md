# 해온 HAEON

### 바람이 키우고, 시간이 빚다.

**전통주의 이야기를 브랜드 경험과 제품 탐색으로 연결한 반응형 웹사이트**

![해온 메인 비주얼](docs/images/main-visual.jpg)

> 자연의 재료, 기다림의 시간, 한 잔의 여운.  
> 해온은 강화도의 자연과 전통 발효를 모티브로 기획한 가상의 프리미엄 한국 약주 브랜드입니다.

## 01. 프로젝트 개요

해온(HAEON)은 브랜드의 기획과 시각적 정체성을 웹으로 구현한 포트폴리오 프로젝트입니다. 바다와 바람, 쌀과 누룩, 시간의 흐름을 이미지와 영상으로 표현하고, 브랜드 이야기를 읽는 과정이 원재료·풍미·제품 탐색으로 이어지도록 구성했습니다.

HTML·CSS·Vanilla JavaScript로 멀티페이지 웹사이트를 구현했으며, 상품 선택부터 장바구니와 결제 전 확인까지의 구매 체험을 제공합니다. 별도의 Python·SQLite 로컬 서버에서는 회원가입과 로그인, 관리자 회원 관리를 확인할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 프로젝트 유형 | 가상의 전통주 브랜드 웹사이트 · 팀 포트폴리오 |
| 제작 목적 | 브랜드 콘셉트와 비주얼 디자인, 웹 구현 결과를 하나의 경험으로 제시 |
| 핵심 키워드 | 자연 · 전통 · 발효 · 시간 · 여운 |
| 주요 콘텐츠 | 브랜드 스토리·CI, 원재료·양조 과정, 풍미·음식 페어링, 제품 컬렉션 |
| 구현 방식 | HTML5 · CSS3 · Vanilla JavaScript 기반 멀티페이지 구성 |
| 화면 대응 | 데스크톱·모바일 반응형 레이아웃 |

## 02. 기획 의도와 사용자 흐름

### 전통의 가치를 시각적인 이야기로 전달

전통주의 재료와 양조 과정을 자연 풍경, 제품 이미지, 짧은 문장으로 풀어냈습니다. 방문자가 브랜드의 분위기를 먼저 느끼고, 탄생 배경과 만드는 과정, 즐기는 방법을 차례로 이해하도록 구성했습니다.

### 브랜드 탐색을 제품 경험으로 연결

**HOME → STORY → CRAFT → TASTE → EXPERIENCE**

메인 화면에서 시작한 관심이 브랜드 이해와 제품 탐색으로 이어집니다. 음식 페어링과 선물용 패키지를 함께 소개해 전통주를 식사와 선물 등 일상의 장면에 연결했습니다.

## 04. 주요 페이지

아래 이미지는 프로젝트의 브랜드 비주얼이며, 웹페이지 전체 화면 캡처는 아닙니다.

### HOME · 브랜드의 첫인상

바다 영상과 제품 이미지를 조합한 히어로 영역으로 해온의 분위기를 전달합니다. 이미지·영상 모자이크 메뉴는 브랜드 이야기, 원재료, 풍미, 제품 컬렉션으로 연결됩니다. 모바일에서도 화면 너비에 맞춘 3열 배치를 적용했습니다.

### STORY & CI · 해온의 이야기와 정체성

![해온 브랜드 스토리](docs/images/brand-story.png)

강화도의 자연과 전통 발효를 바탕으로 브랜드의 배경과 지향점을 소개합니다. STORY / IDEAL 페이지에서 브랜드 이야기를, STORY / MEANING 페이지에서 CI와 시각적 정체성을 전달합니다.

### CRAFT · 자연이 건네고, 시간이 완성한다

![해온 크래프트 — 누룩의 질감](docs/images/craft.jpg)

쌀, 배, 매실, 국화, 누룩의 특징과 역할을 소개합니다. 재료 준비부터 발효와 완성까지의 양조 과정을 5단계로 구성해 제품의 배경을 이해하도록 돕습니다.

### TASTE & PAIRING · 한 끼의 온기, 한 모금의 여운

![해온 풍미와 음식 페어링](docs/images/taste-pairing.png)

브랜드 콘셉트에 따른 목표 풍미와 음용 방법을 안내합니다. 육회, 흰살생선, 샤브샤브, 맥적·갈비, 국화전 등의 페어링 정보를 제공하고, 음식별 상세 설명은 드로어 패널로 확인할 수 있습니다.

### EXPERIENCE · 일상에 스며드는 해온

![해온 제품과 패키지 컬렉션](docs/images/experience.png)

4종의 제품·패키지를 소개하고 상품 상세, 수량 선택, 장바구니, 배송 정보 입력, 결제 전 확인으로 이어지는 구매 체험을 구성했습니다. ACCOUNT는 계정 화면으로, BAG은 장바구니 패널로 연결됩니다.

| 구성 | 시안 가격 |
| --- | ---: |
| 375ml | 22,000원 |
| 750ml | 38,000원 |
| 750ml + 백자잔 2개 | 58,000원 |
| 100ml 4병 + 전용 잔 2개 | 42,000원 |

제품 가격과 풍미는 포트폴리오용 콘셉트입니다. 배송비는 미정이며, 화면의 합계는 상품 금액을 기준으로 합니다.

## 05. 주요 구현 기능

| 기능 | 구현 내용 |

| 메인 비주얼 | HTML5 Video 배경과 제품 이미지, 이미지·영상 모자이크 구성 |

| 관리자 기능 | 회원 조회와 활성 상태 관리 |
| 접근성 요소 | 본문 바로가기, 이미지 대체 텍스트, ARIA 속성, 다이얼로그 포커스 처리 |

### 구현 범위

- **구매 체험:** 실제 결제창 연결, 카드번호 입력, 주문 접수, 구매 완료 기능은 없습니다. 주문내역 화면은 실제 주문이 없다는 안내를 제공합니다.
- **장바구니·배송 정보:** 장바구니는 같은 탭의 세션 저장소를 사용하며 서버 주문 기록을 만들지 않습니다. 배송 정보는 주문 서버나 저장소에 저장하지 않습니다. 주소 검색어는 카카오 서비스로 전송됩니다.
- **회원 기능:** 구매 체험과 별도로 로컬 Python 서버에서 실제 SQLite 계정을 저장합니다. 회원 서버는 로컬 개발용입니다.
- **정적 시연:** 정적 서버에서는 디자인과 구매 체험을 확인할 수 있으며, 회원 API는 Python 서버 실행이 필요합니다.

## 07. 실행 방법

### 회원 기능을 포함한 로컬 실행

Python 3.10 이상 환경에서 `server.py`가 있는 폴더에서 실행합니다.

```powershell
python server.py serve
```

브라우저에서 [로컬 사이트](http://127.0.0.1:8000/)에 접속합니다. 종료는 `Ctrl+C`입니다. 포트를 변경하거나 관리자 계정을 생성할 때는 다음 명령을 사용합니다.

```powershell
python server.py serve --port 8001
python server.py create-admin
```

### 디자인·구매 체험 시연

Node.js가 설치된 환경에서 `haeon` 폴더로 이동해 실행합니다.

```powershell
node serve.cjs
```

[정적 시연 사이트](http://127.0.0.1:4173/)에서 확인합니다. 이 서버와 VS Code Live Server에는 회원 API가 없습니다. 파일을 직접 여는 방식보다 로컬 서버 실행을 권장합니다. Google Fonts와 카카오 주소 검색에는 인터넷 연결이 필요합니다.

## 08. 포트폴리오 발표 흐름

1. **기획 배경** — 자연·전통·시간을 전통주 브랜드에 연결한 방향을 소개합니다.
2. **디자인 표현** — 메인 영상과 제품 비주얼, 컬러·타이포그래피를 보여줍니다.
3. **콘텐츠 구성** — STORY·CRAFT에서 브랜드 배경과 양조 과정의 전달 방식을 설명합니다.
4. **상세 인터랙션** — TASTE의 음식별 페어링 패널을 시연합니다.
5. **구매 체험** — 상품 상세 → 수량 선택 → 장바구니 → 배송 정보 → 결제 전 확인을 보여줍니다.
6. **화면 대응·회원 기능** — 모바일 레이아웃과 로컬 서버의 회원 기능을 구분해 소개합니다.
